# Check-in

Check-in diário por conta (Fase 4): objetivo do dia, até 3 prioridades
(texto livre ou vínculo com conteúdo/meta), conteúdo principal, stories
planejados, produto/campanha em foco, tendência observada, ação de
comunidade, observações, aprendizado do dia, checklist personalizável
(`checklist_items` + `daily_actions`) e fechamento noturno (vitória,
bloqueio, aprendizado, prioridade de amanhã). Autosave de rascunho
(`src/hooks/use-autosave.ts`) e checklist com atualização otimista +
rollback (`src/features/checkin/checklist-section.tsx`).
