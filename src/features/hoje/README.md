# Hoje

Página inicial do app (Fase 4): saudação, foco do dia/mês, cards de
produção (planejados, publicados, atrasados, métricas pendentes, meta
semanal), prioridades do check-in de hoje, conteúdos planejados para hoje e
pendências acionáveis. Dados reais via `src/lib/data/hoje.ts`
(`getHojeSummary`). Sem dados mockados.
